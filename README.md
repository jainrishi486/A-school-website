# 🏫 Vardhman Convent School — Website Project

A fully responsive, premium school website built using
pure HTML, CSS, and JavaScript. No frameworks used.

## 🚀 Features
- Sticky glassmorphism navigation bar
- Animated hero section with floating particles
- Scroll-reveal animations on all sections
- Mobile responsive with hamburger menu
- Contact form with live validation
- Clean, premium UI with gold & navy theme

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
